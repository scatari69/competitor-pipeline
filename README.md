# Competitor Intelligence Pipeline

AI-інструмент для автоматичного аналізу конкурентів: сайти, тарифи, соцмережі, відгуки.
Працює на **локальній LLM** через Ollama — жодних хмарних API і ключів.

## Структура проєкту

```
competitor_pipeline/
├── server.py              — Flask API + SSE стрімінг
├── pipeline.py            — Оркестратор всіх етапів
├── scrapers/
│   ├── web_scraper.py     — Скрейпінг сайтів, тарифів, відгуків
│   └── social_scraper.py  — Публічні дані соцмереж
├── analyzers/
│   ├── llm_client.py      — Клієнт Ollama зі structured output
│   ├── schemas.py         — JSON-схеми кроків аналізу
│   └── ai_analyzer.py     — Покроковий аналіз і порівняльна матриця
├── templates/
│   └── index.html         — Інтерактивний дашборд
├── tests/                 — Тести (працюють без запущеної моделі)
├── results/               — Збережені JSON-результати
└── requirements.txt
```

## Встановлення

```bash
pip install -r requirements.txt
```

## Запуск

1. Встановіть Ollama і завантажте модель ([ollama.com/download](https://ollama.com/download)):

```bash
ollama pull gemma3:4b
ollama serve            # зазвичай уже працює як сервіс
```

2. Запустіть сервер:

```bash
python server.py
```

3. Відкрийте браузер: **http://localhost:5000**

Індикатор угорі панелі показує назву моделі, якщо вона доступна, або причину помилки.

### Налаштування моделі

Усе через змінні оточення, код правити не треба:

| Змінна | За замовчуванням | Призначення |
|--------|------------------|-------------|
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Адреса Ollama (можна винести на іншу машину) |
| `LLM_MODEL` | `gemma3:4b` | Будь-яка модель Ollama: `gemma3:12b`, `qwen3:4b`, `llama3.1:8b` |
| `LLM_NUM_CTX` | `8192` | Розмір контексту в токенах |
| `LLM_TIMEOUT` | `180` | Таймаут одного кроку, секунди (на CPU варто збільшити) |
| `LLM_TEMPERATURE` | `0.2` | Температура |
| `LLM_RETRIES` | `2` | Повтори після помилки |

### Як влаштований аналіз

Модель на 4B параметрів не заповнює структуру з 60 полів за один раз, тому аналіз
розбито на 5 коротких кроків із власною JSON-схемою кожен (`format` в Ollama
гарантує валідний JSON і значення лише з дозволених enum):

1. профіль компанії та якість сайту
2. тарифи
3. соцмережі
4. репутація за відгуками
5. підсумок: загрози, можливості, рекомендовані дії

Кроки без вхідних даних пропускаються без виклику моделі, а падіння одного кроку
не втрачає решту аналізу. Уся арифметика — мін/макс/середня ціна, сума підписників,
бали порівняльної матриці — рахується в Python, бо маленькі моделі помиляються в числах.

## Тести

```bash
pytest                       # усі тести, ~0.1 с, Ollama не потрібна
pytest tests/test_ai_analyzer.py -v
pytest -k "price"            # один тест або група
```

Мережевий шар підмінюється фейковим транспортом (`tests/conftest.py`), тому тести
перевіряють збірку відповіді, обрізання значень до enum і поведінку при збоях моделі
без реальних викликів.

## Використання

### Через дашборд (рекомендовано)

1. Введіть URL конкурента або назву компанії
2. Натисніть «Аналізувати»
3. Спостерігайте за прогресом у real-time
4. Перегляньте повний звіт із тарифами, соцмережами, репутацією
5. Для порівняння — позначте кілька аналізів в «Історії» і натисніть «Порівняти»

### Через командний рядок

```bash
# Аналіз одного конкурента
python pipeline.py https://lanet.ua

# Тест скрейпера
python scrapers/web_scraper.py https://ukrtelecom.ua

# Тест аналізатора
python analyzers/ai_analyzer.py
```

## Що аналізується

| Джерело | Що збирається |
|---------|---------------|
| Сайт | Тексти, навігація, технології, meta |
| Сторінки тарифів | Ціни (UAH), назви пакетів, умови |
| Соцмережі | Facebook, Instagram, Telegram: підписники, контент |
| Відгуки | Фрагменти з Google Search |
| Локальна LLM | Структурований аналіз, загрози, можливості, рекомендації |

## Обмеження

- **Facebook/Instagram**: сильно обмежені без авторизації — отримуємо базові дані
- **Google Search**: скрейпінг може блокуватися (rate limiting)
- **Telegram**: працює добре для публічних каналів
- **Playwright**: для складних JS-сайтів можна розширити web_scraper.py
- **Швидкість**: на CPU gemma3:4b витрачає приблизно 30-90 секунд на крок, тобто
  2-6 хвилин на повний аналіз. З GPU — секунди. Якщо кроки падають по таймауту,
  збільшіть `LLM_TIMEOUT`
- **Якість**: 4B-модель дає стислі та подекуди поверхневі формулювання. Якщо
  висновки замалі — спробуйте `gemma3:12b` або `qwen3:8b` через `LLM_MODEL`

## Розширення

Для моніторингу змін (цін, контенту) — запускайте pipeline за розкладом через cron:

```bash
# Щотижневий моніторинг
0 9 * * 1 cd /path/to/competitor_pipeline && python pipeline.py https://competitor.ua
```
